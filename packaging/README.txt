SterMusic — music player for Linux
==================================

Install (no sudo, for your user only):

    ./install.sh

SterMusic then shows up in the application menu. To remove it: ./uninstall.sh

Requirements: glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Linux Mint 21, Fedora 36 and
later) and the ALSA sound library (libasound2), present almost everywhere.
Recommended: ffmpeg (Opus, WMA, APE, WavPack, DSD, conversion, CD ripping).

On Kubuntu, Ubuntu or Debian, the .deb package is simpler: double-click it, or run
"sudo apt install ./stermusic_…_amd64.deb".

The interface follows your desktop language (English or French); change it in
Settings → Language.

License: free software, GNU GPL version 3 or later (LICENSE). Credits (images, icons, fonts) are
in CREDITS.md, the licenses of the libraries used in THIRD-PARTY-LICENSES.txt.
